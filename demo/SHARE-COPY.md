## Files and use

- `osteon-demo.mp4`: approximately 66 seconds, 1920 × 1080, H.264 MP4. For a README link, class presentation, or landscape post.
- `osteon-social.mp4`: approximately 23 seconds, 1080 × 1920, H.264 MP4. For vertical social video or class group sharing.
- `poster.jpg` and `social-poster.jpg`: widescreen and vertical covers.
- `preview.gif`: nine-second animated README preview.
- `screenshots/`: eight unaltered application screenshots.
- `.vtt`: complete English narration captions. The social edit also has speech captions over app scenes and equivalent closing card text.
- `osteon-narration.wav` and `osteon-social-narration.wav`: final paced, normalized voice tracks.
- `osteon-voice-workflow.json`: compact editable ComfyUI workflow; `osteon-narration-api.json` holds the eight-take production graph.
- `NARRATION-SCRIPT.md`, `TTS-WORKFLOW.md`, and `voice-reference.wav`: script, tested setup/model comparison, and the designed synthetic reference.

Both MP4s have a warm conversational female narrator, generated locally using Qwen3-TTS 1.7B in ComfyUI. No real-person recording was cloned and no third-party music is included.

The README links to the video page because GitHub Markdown does not reliably play repository MP4 files inline. Share the demo page to give viewers playback, download links, a transcript, and credits in one place. Social publishing itself remains with you; these files do not post to any account.

## Accurate claims

This is an independent student study aid, not an official OpenStax or college product. The app covers the chapter inventory and preserves the 177-item course checklist. Some anatomy is a labeled teaching reconstruction. Eight textbook features currently have unresolved spatial targets and are excluded from scored locating; do not advertise every feature as independently validated native 3D anatomy. See the live accuracy report.

Optional local tutoring requires separate Ollama setup. The base atlas, chapter material, and practice do not require Ollama.
